How to validate Israeli ID numbers

An Israeli ID number has nine digits, and the last digit is a check digit calculated from the first eight. A mistyped number almost always fails the test, which makes it a quick way to catch data-entry errors.

  1. Paste one ID or company number per line.
  2. Each line is tested against the check-digit rule.
  3. Review the valid and invalid lines and fix or remove the bad ones.

A passing result means the number is correctly formed. It does not prove the number was issued to anyone, and it does not tell you whose it is. Never treat the check as identity verification. Leading zeros matter, so make sure your source did not drop them.

Frequently asked questions

How is the check digit calculated?

Digits are multiplied by 1 and 2 alternately, products above 9 have their digits added, and the total must divide by 10.

Why was my number rejected?

Usually a typo, a swapped pair of digits or a missing leading zero.

Does this contact any government database?

No. It only applies the arithmetic rule, in your browser.

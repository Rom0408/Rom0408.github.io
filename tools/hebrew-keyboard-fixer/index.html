How to fix text typed on the wrong keyboard layout

Everyone has done it: you start typing and notice the keyboard was set to English, so שלום came out as "akuo". Nothing is lost. Each key still maps to one Hebrew letter, and the mapping can be reversed.

  1. Paste the garbled text into the input box.
  2. The tool detects whether the text is English keys that should be Hebrew, or the reverse, and converts it.
  3. Copy the corrected text from the output box.

Convert one pasted block at a time. Punctuation keys are part of the Hebrew layout too: on the standard Israeli layout the comma key types ת and the period key types ץ, so a sentence typed by mistake can look odd until it is converted.

Frequently asked questions

Does it work from Hebrew back to English?

Yes. If Hebrew letters were typed where English was expected, it converts them to the Latin keys.

Does it fix text that is shown backwards?

No. This tool fixes the keyboard layout only. Text that appears in reversed order is a different problem.

Does it use the Israeli standard layout?

Yes, the standard Hebrew layout found on Israeli keyboards.

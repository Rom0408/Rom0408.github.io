How to test a regex before using it in a sheet

A regular expression that is slightly wrong can quietly damage a whole column. Testing it on a few sample lines first costs a minute and avoids that.

  1. Type your pattern in the pattern box.
  2. Paste sample text, ideally including awkward rows that you expect to fail.
  3. Check the matches. If you are replacing, enter the replacement and review the preview.
  4. When the result is right, copy the pattern into your formula or find-and-replace.

Google Sheets uses the RE2 engine, which has no lookahead or backreferences in the pattern. This tester runs in your browser with JavaScript, so a pattern that works here can still be rejected in Sheets. Keep to the common features and test in Sheets once.

Frequently asked questions

Why does my pattern work here but not in Sheets?

The two use different regex engines. Features such as lookahead are supported in JavaScript but not in the RE2 engine behind Sheets functions.

How do I match digits only?

Use \d+ to match one or more digits.

Does it store my sample text?

No. Everything stays in your browser.

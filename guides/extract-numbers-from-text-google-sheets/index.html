Extract numbers from text in Google Sheets

Pull the first number or all the numbers out of a text cell in Google Sheets using REGEXEXTRACT and REGEXREPLACE.

Order references, invoice numbers and prices are often buried in sentences. Sheets has regular expression functions built in, and they cover the common cases.

1. Get the first number

\d+ matches a run of digits, and REGEXEXTRACT returns the first match.

=REGEXEXTRACT(A2,"\d+")

2. Turn it into a number

The result is text. Multiply by 1 or wrap it in VALUE when you want to calculate with it.

=VALUE(REGEXEXTRACT(A2,"\d+"))

3. Get all the numbers

Replace everything that is not a digit with a space, then split and join.

=TEXTJOIN(", ",TRUE,SPLIT(TRIM(REGEXREPLACE(A2,"\D+"," "))," "))

4. Test the pattern first

Try the pattern against a few real examples in the regex tester before filling down a column.

Watch out for

These patterns treat 1,234.50 as three separate numbers. If decimals and thousands separators matter, use a pattern such as \d+\.?\d* and test it carefully. Sheets uses RE2, which has no lookahead.

Frequently asked questions

What if there is no number in the cell?

REGEXEXTRACT returns an error. Wrap it in IFERROR to show a blank.

Can I extract only the 4-digit numbers?

Yes. Use \d{4}, though a longer number would also match its first four digits.

Pad Israeli ID numbers with leading zeros in Google Sheets

Why spreadsheets drop leading zeros from Israeli ID numbers, and three ways to restore the nine digits in Google Sheets.

An ID such as 039337423 turns into 39337423 the moment a spreadsheet reads it as a number. Systems that expect nine digits will then reject it.

1. Restore the zeros with TEXT

This turns a number into a nine-character text value.

=TEXT(A2,"000000000")

2. Or use RIGHT, which also works on text

Add nine zeros in front and keep the last nine characters.

=RIGHT("000000000"&A2,9)

3. Convert the column to values

Copy the new column and paste it with Paste special, Values only, so the padded IDs no longer depend on the original column.

4. Prevent the problem next time

Before pasting new IDs, select the column and choose Format, Number, Plain text. Plain text keeps leading zeros as typed.

Watch out for

A custom number format of 000000000 only changes how the number looks. The cell still holds 39337423, and exports or lookups will use that value. Use a formula or plain text when the stored value matters.

Frequently asked questions

Why does my CSV lose the zeros?

Opening a CSV as numbers drops them. Import the column as plain text.

Is there a function that pads for me?

Not yet. PADID, which will pad to nine digits in one call, is planned for the Israel Business Pack, coming soon. Until then, use the formula above.

A gematria formula for Google Sheets

Calculate the standard gematria value of Hebrew words in Google Sheets with a lookup table and an array formula.

Standard gematria (mispar hechrechi) gives each Hebrew letter a fixed value. With a small lookup table, Sheets can add up the letters of any cell.

1. Build the letter table

In D2:E23 put the 22 letters in column D and their values in column E: א=1 to ט=9, י=10, כ=20, ל=30, מ=40, נ=50, ס=60, ע=70, פ=80, צ=90, ק=100, ר=200, ש=300, ת=400.

2. Map final letters to regular ones

Final forms ך ם ן ף ץ count the same as כ מ נ פ צ in this method, so replace them first.

3. Sum the letters

The formula splits the text into characters, looks each one up and adds the values. Characters that are not in the table, including nikud and spaces, give zero.

=ARRAYFORMULA(SUM(IFERROR(VLOOKUP(MID(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(A2,"ך","כ"),"ם","מ"),"ן","נ"),"ף","פ"),"ץ","צ"),SEQUENCE(LEN(A2)),1),$D$2:$E$23,2,FALSE),0)))

4. Test on a known word

שלום should give 376, which matches the free calculator.

Watch out for

Other gematria methods exist, for example one that gives final letters separate values, and they give different totals. Say which method you use when you share results.

Frequently asked questions

Do I have to type the table?

Yes, once. It is 22 rows. The Toolkit add-on has a GEMATRIA function so you do not need a table.

Does nikud change the value?

No. Marks are not in the table, so they count as zero.

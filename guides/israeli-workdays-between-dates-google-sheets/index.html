Count Israeli workdays between two dates in Google Sheets

Use NETWORKDAYS.INTL with a Friday-Saturday weekend and a holiday list to count working days in Israel in Google Sheets.

The default NETWORKDAYS function assumes a Saturday and Sunday weekend, which is wrong for most Israeli workplaces. NETWORKDAYS.INTL lets you choose the weekend and list the holidays.

1. Build a holiday list

Put the dates of public holidays in a range such as H2:H30, one per row. Take them from the official Israeli calendar for each year.

2. Count working days with a Friday and Saturday weekend

Weekend code 7 means Friday and Saturday. The count includes both the start and the end date.

=NETWORKDAYS.INTL(A2,B2,7,$H$2:$H$30)

3. Use a string if your week differs

A seven-character string runs Monday to Sunday, where 1 marks a day off. A week with only Friday and Saturday off looks like this.

=NETWORKDAYS.INTL(A2,B2,"0000110",$H$2:$H$30)

4. Check against the free calculator

Run one date pair through the Israeli workdays calculator to confirm the numbers look right.

Watch out for

Holiday dates change each year, so the list needs updating every year from an official source. Holiday eves and half-days at your employer are not handled by any date function.

Frequently asked questions

What does weekend code 7 mean?

Friday and Saturday are the days off.

Does the function include the start date?

Yes. Both the start and the end date are counted when they are workdays.

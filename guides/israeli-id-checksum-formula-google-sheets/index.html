Israeli ID checksum formula for Google Sheets

A copy-and-paste Google Sheets formula that tests the check digit of Israeli ID (teudat zehut) and company numbers.

Israeli ID numbers have nine digits with a built-in check digit. A short formula can flag mistyped numbers across a whole column before they reach a form or a payment system.

1. Know the rule

Pad the number to nine digits. Multiply the digits by 1, 2, 1, 2, 1, 2, 1, 2, 1 in order. When a product is greater than 9, subtract 9 from it, which equals adding its two digits. The sum must be divisible by 10.

2. Paste the formula

With the number in A2, this returns TRUE when the check digit is right.

=MOD(SUMPRODUCT(ARRAYFORMULA(LET(p,MID(RIGHT("000000000"&A2,9),SEQUENCE(9),1)*{1;2;1;2;1;2;1;2;1},p-9*(p>9)))),10)=0

3. Fill down and filter

Copy the formula down the column and filter for FALSE to find numbers to fix.

4. Reject empty and all-zero values

Zeros pass the arithmetic, so add a test such as A2>0 around the formula if blank cells could appear.

Watch out for

The test only checks the format. A number can pass and still not have been issued to anyone, and it cannot confirm identity. Leading zeros are often lost when files are opened, so keep the column as text.

Frequently asked questions

Does a passing number mean the ID is real?

No. It means the number is correctly formed. It says nothing about whether it was issued.

Does the same rule apply to company numbers?

Company numbers use the same nine-digit check, and the free validator accepts them too.

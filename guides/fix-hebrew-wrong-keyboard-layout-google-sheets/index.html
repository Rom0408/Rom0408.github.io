Fix wrong-layout Hebrew in Google Sheets

Convert text typed with the wrong keyboard layout, such as akuo instead of שלום, in Google Sheets with a lookup table or a function.

When someone enters Hebrew with the English layout on, the cell holds Latin letters that map one-to-one to Hebrew letters on the Israeli keyboard. A lookup table converts them back.

1. List the key mapping

On the standard Israeli layout the Latin keys give these letters. Put the Latin key in D2:D30 and the Hebrew letter in E2:E30.

q /   w '   e ק   r ר   t א   y ט   u ו   i ן   o ם   p פ
a ש   s ד   d ג   f כ   g ע   h י   j ח   k ל   l ך   ; ף
z ז   x ס   c ב   v ה   b נ   n מ   m צ   , ת   . ץ

2. Convert each character

The formula looks every character up in the table and keeps unknown characters as they are.

=ARRAYFORMULA(JOIN("",IFERROR(VLOOKUP(MID(LOWER(A2),SEQUENCE(LEN(A2)),1),$D$2:$E$30,2,FALSE),MID(A2,SEQUENCE(LEN(A2)),1))))

3. Check an example

akuo should become שלום. If you get an error, make sure the table has the key in column D with no extra spaces.

4. Convert in the other direction

For Hebrew typed where English was meant, look up in column E and return column D, using INDEX and MATCH.

Watch out for

The result is only right when the text was typed on the standard layout, and cells that mix correct and wrong text need a manual look. Sentence punctuation is part of the mapping.

Frequently asked questions

Can I fix many cells at once?

Yes, wrap the formula in ARRAYFORMULA over a range or fill it down.

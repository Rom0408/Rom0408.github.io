Add working days to a date, Israeli week, in Google Sheets

Find a due date N working days from a start date in Google Sheets using WORKDAY.INTL with a Friday-Saturday weekend and holidays.

Delivery dates, SLAs and payment terms are usually counted in working days. WORKDAY.INTL does that, and it lets you choose which days are the weekend.

1. Prepare the holiday range

Keep the holiday dates in a range such as H2:H30. Fill it from the official calendar and update it yearly.

2. Add working days

Weekend code 7 means Friday and Saturday off. A start on Thursday plus one workday returns Sunday.

=WORKDAY.INTL(A2,10,7,$H$2:$H$30)

3. Go backwards

Use a negative number to find a date N working days before a deadline.

=WORKDAY.INTL(A2,-5,7,$H$2:$H$30)

4. Format the result

If you see a number such as 45300, format the cell as a date with Format, Number, Date.

Watch out for

The start date itself is not counted, so adding 1 workday to a Thursday gives Sunday. If your business works on some Fridays, use the string form of the weekend argument or a custom approach, since WORKDAY.INTL treats the same days off every week.

Frequently asked questions

Why does my result land on a holiday?

The holiday range is empty, incomplete or holds text instead of dates.

How do I calculate the next working day?

Add 1 workday with the same formula.

Highlight matching values in two columns in Google Sheets

Use conditional formatting with COUNTIF to colour cells in column A that also appear in column B, or duplicates within one column.

Colours are quicker to scan than a filtered list. Conditional formatting with a custom formula highlights matches as they appear and updates when the data changes.

1. Select the range

Select A2:A, the column you want to colour.

2. Open conditional formatting

Choose Format, then Conditional formatting. Under Format cells if, choose Custom formula is.

3. Highlight values that also appear in B

Pick a fill colour and press Done. Every value in column A that also exists in column B turns that colour.

=COUNTIF($B$2:$B,$A2)>0

4. Highlight duplicates inside a single column

Use this rule when you only have one column and want to see repeated values.

=COUNTIF($A$2:$A,$A2)>1

Watch out for

COUNTIF ignores capitals but treats a trailing space as a difference, and it can treat characters such as * and ? in the criteria as wildcards. Clean the text first. For long lists, extract the results into a new column with FILTER, as in the compare guide.

Frequently asked questions

How do I remove the duplicates instead?

Use Data, Data cleanup, Remove duplicates, or the UNIQUE function for a deduplicated copy.

Will it update automatically?

Yes. The rule re-evaluates whenever the data changes.
